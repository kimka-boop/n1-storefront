## 1. Smart Fit 데이터란

사용자가 스마트 핏에서 알려준 최소 선호 정보:

| 필드 | 예시 | 성격 |
|---|---|---|
| 선호 핏 | 슬림/정사이즈/여유 (A/B/C) | 개인화 취향 |
| 평소 상의 사이즈 | 100, M, FREE | 개인화 앵커 |
| 평소 하의 사이즈 | 30~31 | 개인화 앵커 |
| (레거시) 성별 | 미지정 | 판단에 사용되지 않음 — V2에서 질문하지 않음 |

민감정보(신체 치수, 건강, 인종 등)를 수집하지 않는다. 사용자가 직접 말한
"선호"만 저장한다.

## 2. 게스트 (비회원)

- **영구 저장 금지**: 게스트의 핏 컨텍스트는 서버·Customer Sheet(localStorage
  포함 영구 저장소)에 절대 저장하지 않는다.
- **세션 경계**: 브라우저 sessionStorage에만 저장한다 — 같은 탭에서 PDP 이동·
  새로고침·카트 이동에도 유지되고, 탭을 닫으면 사라진다.
- 결과 화면은 이를 정직하게 말한다: "지금은 제가 잠깐 기억하고 있어요."

## 3. 회원

- **목적 제한**: 저장 목적은 쇼핑 개인화(핏 추천·사이즈 해석)뿐이다. 마케팅
  프로파일링이나 제3자 제공에는 사용하지 않는다.
- **저장 위치**: (1) 회원 기기 localStorage — 다른 기기로 옮겨지지 않는 기기
  기억. (2) 서버 Users 시트 — 계정 기억(다른 기기에서 이어짐). 시트에는 핏
  취향·사이즈·(미지정)성별만 저장되고, 비밀번호는 scrypt 해시만 저장된다.
- **사용자 권리 — view / edit / reset**: 스마트 핏 결과 화면에서 언제든
  (1) 저장된 값을 볼 수 있고, (2) 설정 수정으로 바꿀 수 있고, (3) 초기화로
  기기·서버 양쪽에서 지울 수 있다. 로그아웃만으로는 서버 핏이 지워지지 않는다 —
  초기화가 지우는 장치다.

## 4. 회원 탈퇴 시 (정책 초안 — 구현 전)

- **개인화 데이터**: 탈퇴 시 Users 시트의 해당 행에서 핏 프로필(성별/기준사이즈/
  핏취향)과 식별 정보(아이디/이메일)를 삭제한다. `lib/emailVerify.ts`의
  `SMARTFIT_ON_WITHDRAWAL = DELETE_PERSONALIZATION_KEEP_ORDER_RECORDS`가 코드측
  계약 자리표다. (탈퇴 API는 이번 세션 범위 밖 — 정책 선석 only)
- **주문/결제 기록과의 분리**: 주문·결제·CS 기록은 전자상거래법상 보존 의무 등
  별도 근거로 **별도 보존**한다. 스마트핏 개인화 데이터는 주문 기록과 한 몸이
  아니며, 탈퇴해도 주문 기록 보존이 개인화 데이터 보존을 정당화하지 않는다.
- 정확한 보존 기간·근거 법조문은 법률 검토 후 확정한다(이 초안이 창작하지
  않는 부분이다).

## 5. 보안 (구현 사실)

- 비밀번호는 scrypt(N=16384) + 랜덤 salt 해시로만 저장 — 평문은 프론트 영구
  저장소·시트·로그 어디에도 남지 않는다.
- 게스트 핏은 절대 서버로 전송되지 않는다(세션 저장소 전용 경로).
- 이메일 소유 확인은 EMAIL_VERIFY_DEFERRED 계약으로 지연된다 — 확인되지 않은
  이메일로 계정 복구 채널을 열지 않는다(docs/N1_EMAIL_VERIFY_DEFERRED.md).

## 6. 미해결 항목 (다음 검토 대상)

1. 회원 탈퇴 API 구현 + Users 시트 행 삭제 범위 확정.
2. 이메일 인증 provider 승인 시 EMAIL_VERIFY_DEFERRED 해제 절차.
3. 미성년자·14세 미만 동의 등 연령 정책 — 현재 수집 구조상 질문하지 않음.
4. 본 정책의 서비스 내 고지 위치와 문구(법률 검토 후).
